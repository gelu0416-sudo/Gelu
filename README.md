# 单品利润核算系统

一个无需安装依赖的静态前端页面，用于跨境电商单品利润核算。

## 已支持场景

- 国内发货单品利润核算 - 自然流
- 国内发货单品利润核算 - 爆款推流
- 国外发货单品利润核算 - 爆款推流

## 使用方式

直接在浏览器打开 `index.html` 即可使用。

## 当前核算逻辑

- 销售收入按 `售价 × 汇率 × 签收率` 折算为人民币
- 平台佣金、支付手续费、售后备付按收入比例计算
- 爆款推流场景额外计入广告消耗、达人佣金、活动补贴
- 国外发货场景额外计入头程、海外仓、尾程、仓储损耗
